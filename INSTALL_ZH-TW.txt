13SoulMU Standard 2.1.1（Windows x64）

1. 執行「13SoulMU.Standard.Setup.2.1.1.exe」並完成安裝。
2. 開啟 13SoulMU Standard；剪輯與離線字幕不需登入、不需個人 API Key，也不必另外安裝 Node.js、Git、FFmpeg、Whisper 或模型。
3. 建立專案、匯入影片或音訊。開啟「字幕」面板，按「自動字幕」即可離線辨識。完成後請自行校對錯字；一般電腦使用 CPU，辨識時間依影片長度和電腦效能而異。

用 Claude Code／Codex 控制剪輯

1. 先安裝並登入你自己的 Claude Code 或 Codex CLI。AI 用戶端本身的網路、方案與帳號需求，依各服務規定；一般版本機 MCP 不使用講師的個人 API Key。
2. 打開一般版「設定 → MCP 連線」，開啟「允許 AI 透過 MCP 控制」。預設為關閉。
3. 按「測試連線」，確認顯示成功。
4. 複製對應用戶端指令，貼到 Windows PowerShell 執行。指令從這台電腦讀取自動產生的連線金鑰，不含金鑰明文。指令會設定本次 PowerShell 與目前 Windows 使用者的 THIRTEENSOUL_MCP_TOKEN 環境變數。
5. 從同一個 PowerShell 視窗啟動 claude 或 codex。原本已開啟的用戶端請重新啟動；需要時登出再登入 Windows，讓其他啟動程式取得更新後的環境變數。
6. 已有同名 13soulmu 連線時，先在該用戶端移除舊連線再加入。連接埠變動時也需重新設定。
7. 一般版必須保持開啟。AI 可建立、修改、刪除專案及匯出影片，操作前請先儲存介面上的修改，並確認時間軸結果。
8. 若提示專案有外部更新或存檔衝突，本次舊存檔不會覆蓋最新專案；請保留需要的本機修改內容，重新開啟專案確認後再操作。介面尚未儲存的修改不會自動合併。
9. 「重新產生連線金鑰」會使舊金鑰失效，之後重新複製指令執行並重新啟動用戶端。停用 MCP 後不再接受新連線；已開始的剪輯或輸出可能仍會完成。

範例：
「先列出專案。建立一個 16:9、30 秒的專案，把我指定的四支影片與一首配樂匯入，依序排上時間軸、影片靜音、配樂淡入淡出，再匯入指定的 SRT。請先讓我確認時間軸，再輸出 1080p MP4。」

MCP 提供 76 個一般版工具，包括專案、素材、時間軸、SRT、內建離線自動字幕與輸出。不開放雲端 AI 生圖／生影片、TTS、分鏡板、前製與計費工具。
連線只綁定 127.0.0.1，拒絕瀏覽器跨站請求。連線金鑰僅在學員首次啟用時產生，保存在此電腦的一般版使用者資料中，請勿轉傳 mcp.json。
